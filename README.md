# HubCli

HubCli é um agente de programação multi-LLM para terminal, baseado no projeto open source OpenCode.

Este fork não é afiliado nem mantido pela equipe oficial do OpenCode.

## Uso

```bash
bun run dev
```

## Créditos

HubCli é baseado no OpenCode, licenciado sob MIT.
